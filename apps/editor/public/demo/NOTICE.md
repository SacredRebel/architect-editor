# Demo site and house

`site-house.json` is the H19 scene fixture, byte for byte (sha256 `abdcd20c…`): generated by
`packages/viewer/test/fixtures/make-h19-scene.mjs` on branch `eco/h19-2` (commit `36d4f897`), whose
`MANIFEST.md` records every asset. The editor opens it when the world's studio sends no scene or
site and the editor holds no design (`apps/editor/lib/demo-site.ts`).

| Asset | Source | Licence |
|---|---|---|
| House: 8 walls, 4 rooms, 1 floor slab, 3 doors, 3 windows, a gable roof, 1 stair | node data built with core's own parsers | ours — no geometry files |
| Terrain: 97 × 97 heightfield at 2.5 m, flat within 45 m of the house | closed-form synthetic relief | ours — no survey, scan or purchased data |
| Site guides: lot boundary and house frame | this repository | ours |
| Site location `originLL` −119.1554, 34.4331 | plugin-eco's default sun location | not a parcel; no owner data |
| 20 furniture items and 30 catalog trees | `apps/editor/public/items/<id>/` (Pascal item library) | Pascal's own — upstream `pascalorg/editor`, MIT, © 2026 Pascal Group Inc. |

Item URLs are written `{{origin}}/items/<id>/…` and filled in with the editor's own origin.
